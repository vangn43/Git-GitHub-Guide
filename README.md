# A Beginner's Guide to Git and GitHub

## Project Description
This project is for my Module 6 Assignment. The goal is to create a simple guide that helps beginners to understand how to use Git and GitHub.

## What This Guide Covers
- What Git and GitHub are
- How to create a GitHub repository
- How to use git add, commit, and push
- How brancheds work
- How to create and merge pull requests

## Project Goal
The goal of this project is to help beginners learn Git commands and understand how GitHub works.

## Tools Used
- Git
- GitHub
- Visual Studio Code
