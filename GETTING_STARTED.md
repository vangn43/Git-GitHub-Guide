# Getting Started with Git and GitHub

## Introduction
This guide explains the basics of using Git and GitHub. It will help beginners understand how to manage the projects and keep track of the changes to their code.

## What is Git?
Git is a version control tool that helps developers track changes to their code. It allows them to go back to previous versions if they make a mistake.

## What is GitHub?
GitHub is a website where developers can store their Git repositories online. It also makes it easier to share projects and work with other people.

## Why is Version Control Useful?
Version control is useful because it saves the history of changes made to a project. If something goes wrong, you can check the older versions instead of starting over.

## How to create a GitHub Repository
1. Go to GitHub.com and sign in.
2. Click the New repository button.
3. Enter a name for your repository.
4. Choose whether the repository is public or private.
5. Select Add a README file.
6. Click Create repository.

## How to Clone a Repository
1. Open your repository on GitHub.
2. Click the green Code button.
3. Copy the HTTPS URL.
4. Open VS Code.
5. Press Ctrl + Shift + P and select Git: Clone.
6. Paste the URL and choose where to save the repository.

## Basic Git Commands

### git add
This command stages changes so they are ready to be committed.

### git commit
This command saves your staged changes locally with a message explaining what you changed.

### git push
This command uploads your local commits to GitHub.

### git pull
This command downloads and integrates the changes from a remote repository.
