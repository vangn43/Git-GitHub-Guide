# Merge Conflict Resolution

## What Caused the Conflict?
I created two branches called conflict/first-edit and conflict/second-edit. Both branches changed the same sentence in README.md, but with different wording.

## How I Resolved It
1. I merged conflict/first-edit into main.
2. I created a pull request for conflict/second-edit.
3. GitHub detected a conflict in README.md.
4. I clicked Resolve conflicts.
5. I selected Accept current change to keep the second branch's version.
6. I marked the conflict as resolved and commited the merge.
7. I merged Pull Request #6 into main.

## What I Learned
I learned that merge conflicts can heppen when two branches change the same part of a file. GitHub will let you review the changes and choose which version to keep.
